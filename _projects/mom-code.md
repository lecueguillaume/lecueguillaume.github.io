Several implementations of Median of Means estimators are available:

1. [Charles Laroche's repository](https://github.com/CharlesLaroche/MOM_API) for LASSO, ElasticNet, SVM, linear regression, cross-validation and deep neural networks. All MOM estimators use the `BaseEstimator` class from scikit-learn.
2. [My GitHub repository MOMpower](https://github.com/lecueguillaume/MOMpower), with the notebooks of the papers on [robust machine learning by median-of-means](/publications/) and [robust classification via MOM minimization](/publications/).

Other approach for robust mean estimation: the smoothed random perturbations estimator from Matthew J. Holland, available [here](https://github.com/feedbackward/1dim).
